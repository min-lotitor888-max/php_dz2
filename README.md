# PHP Console Division Script: Basic and Interactive Versions

Учебный проект: консольный скрипт на PHP для деления двух целых чисел с валидацией ввода и обработкой ошибок.

## Задачи и файлы

### Базовый вариант (строго по ТЗ)
Файл: `index.php`

Реализует требования задания:
- Принимает два значения из потока `STDIN`.
- Проверяет, что оба значения являются целыми числами.
- Выводит ошибки в поток `STDERR`:
  - «Введите, пожалуйста, число» — если значение не является числом.
  - «Делить на 0 нельзя» — если второе число равно нулю.
- Выводит результат деления в `STDOUT`.

### Улучшенный вариант (интерактивный ввод)
Файл: `index_moder.php`

Усложнённая версия:
- Реализует циклический ввод: если пользователь ввёл некорректное значение, скрипт запрашивает ввод заново, пока не получит целое число.
- Сохраняет корректную обработку ошибок через `STDERR`.
- Содержит комментарий о том, что это расширенная реализация по сравнению с базовым ТЗ.

## Как запустить

Оба скрипта предназначены для запуска в командной строке (CLI).

```bash
# Базовый вариант
php index.php

# Улучшенный (интерактивный) вариант
php index_moder.php
